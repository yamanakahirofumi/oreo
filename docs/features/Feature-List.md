# 機能一覧

OREO (**Overpowered Rich Editor for Overlords**) に搭載される機能の一覧です。

## 1. 基本コンセプト
- **OS非依存**: Windows, macOS, Linuxで動作します。
- **シンプル・ミニマル**: 装飾を最小限に抑えたビジュアル。

## 2. デザイン方針
- **デフォルト・シンプル**: 初期状態では極力メニューやボタンを隠し、クリーンな外観を提供します。

## 3. エディタ機能
- **タブ機能**: 複数のファイルを同時に開き、タブで切り替えて編集する機能。
    - **未保存変更のインジケータ**: 編集中の内容に変更がある場合、タブのファイル名に `*` を表示。
- **視認性向上機能**:
    - **行番号表示**: エディタ左端に行番号を表示。設定で ON/OFF 切り替え可能。
    - **カレント行強調**: 編集中の行の背景色や行番号を際立たせる。
    - **カーソルカスタマイズ**: 視認性の高い形状や色への変更。
- **条件付きスタイル表示**: テキストの内容に応じて、色、太字、イタリック、下線などのスタイルを動的に適用する機能。
- **ファイルの保存**: `Ctrl+S` (または `Cmd+S`) によるファイルの保存機能。新規ファイルの場合は保存ダイアログを表示。
- (検討中) ファイルの読み込み
- **コマンドショートカット**: Emacsスタイルのマルチストローク・キーバインドによる操作。
- **コマンドパレット (M-x)**: コマンド名による機能の検索と実行。
- **ステータスバー / ミニバッファ**: 画面最下部でカーソル位置やエディタの状態、コマンド入力を表示。
    - **マルチセクション対応**: フッターを N 分割して情報を整理して表示可能（デフォルト 3 分割）。

## 4. 拡張機能・高度な機能
- **Markdownプレビュー**: 編集中のMarkdownファイルをリアルタイム、あるいはコマンドによって描画（レンダリング）して表示する機能。
- **プラグインシステム**: 外部Jarやスクリプトによる機能拡張。
- **LSPクライアント (将来計画)**: Java開発補助を含む、各種言語のコード補完・静적解析の「最低限のサポート」。IDEに頼らないクイックな編集・確認を目的とします。
