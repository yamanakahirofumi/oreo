# キーボード操作の詳細仕様

OREOにおける「キーボード中心の操作」を具体化するための仕様案です。

## 1. 基本方針
- マウスを使わずに全ての主要機能（編集、ファイル操作、設定変更、ウィンドウ管理）にアクセス可能とする。
- Emacsスタイルの「プレフィックスキー（Ctrl-x 等）」と「コマンド名入力（Meta-x）」をベースとする。
- OSごとの慣習を尊重し、macOSでは `Command`、Windows/Linuxでは `Ctrl` を主要な修飾キー（Shortcutキー）として使用する。
- 入力のフィードバックは、画面最下部の「ミニバッファ（ステータスエリア）」に表示する。

## 2. 修飾キーの対応 (Modifier Keys)
クロスプラットフォーム環境での一貫性と、OSネイティブな操作感を両立するため、以下の抽象化を行う。

| 抽象キー | macOS | Windows / Linux | 備考 |
| :--- | :--- | :--- | :--- |
| **Shortcut** | `Command` (⌘) | `Control` (Ctrl) | ファイル保存、コピー＆ペーストなどの標準操作 |
| **Control** | `Control` (⌃) | `Control` (Ctrl) | Emacsスタイルの操作 (C-x, C-f等) |
| **Meta** | `Option` (⌥) / `Esc` | `Alt` / `Esc` | Emacsスタイルの操作 (M-x等) |

- **注意**: Emacsスタイルの `Ctrl-x` などの操作は、macOSにおいても `Control` キーを使用することを基本とする（多くのターミナルやエディタの慣習に準拠）。一方で、`Command+S` などのシステム標準に近い操作は `Command` キーを優先する。

## 3. キーバインドの構造
マルチストローク・キーバインドをサポートし、以下の階層構造を持つ。

| プレフィックス | 分類 | 例 |
| :--- | :--- | :--- |
| `Ctrl-x` | ファイル・バッファ操作、基本コマンド | `Ctrl-x Ctrl-s` (保存), `Ctrl-x b` (バッファ切替) |
| `Meta-x` | コマンド実行 (M-x) | `Meta-x search-replace` |
| `Ctrl-c` | モード固有・拡張コマンド | (将来的な拡張用) |
| `Ctrl-h` | ヘルプ、ショートカットの発見 | `Ctrl-h k` (キーバインドの確認) |

## 4. ミニバッファ (Mini-buffer) の役割
エディタの最下部に位置し、以下の役割を担う。

- **エコーエリア**: 実行したコマンドのログや、エラーメッセージの表示。
- **入力プロンプト**: `Meta-x` 実行時のコマンド名入力や、検索文字列の入力。
- **補完候補の表示**: コマンド入力時に、利用可能なコマンドの候補を表示する。

## 5. キーボードによるナビゲーション
- **ウィンドウ分割**: `Ctrl-x 2` (水平分割), `Ctrl-x 3` (垂直分割), `Ctrl-x 0` (ウィンドウを閉じる)。
- **フォーカス移動**: `Ctrl-x o` で分割されたウィンドウ間を移動する。
- **バッファ切り替え**: `Ctrl-x b` で開いているファイルのリストから選択（ミニバッファでの補完）。

## 6. 発見性 (Discoverability) の確保
キーボード主体の操作は学習コストが高いため、以下の仕組みを検討する。
- **不完全なキー入力へのガイド**: `Ctrl-x` だけ押して数秒待つと、次に押せるキーのヒントが表示される。
- **コマンド検索**: `Meta-x` で曖昧検索（Fuzzy Search）をサポートし、機能名から操作を探せるようにする。
