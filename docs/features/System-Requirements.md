# 最低動作環境・推奨スペック

本ドキュメントでは、OREOを快適に利用するために必要なシステムの最低スペックおよび推奨スペックを定義します。

## 1. 動作環境の考え方

本アプリは JavaFX を利用したデスクトップアプリケーションです。
カスタム JRE を同梱して配布することを想定しているため、ユーザー側で Java を個別にインストールする必要はありません。

## 2. システム要件

| 項目 | 最低スペック (Minimum) | 推奨スペック (Recommended) |
| :--- | :--- | :--- |
| **OS** | Windows 10/11 (64-bit)<br>macOS 11.0 Big Sur 以上<br>Linux (Ubuntu 22.04 以上等) | Windows 10/11 (64-bit)<br>macOS 13.0 Ventura 以上 |
| **CPU** | Dual Core 2.0 GHz 以上 | Quad Core 2.5 GHz 以上 |
| **メモリ (RAM)** | 4 GB 以上 | 8 GB 以上 |
| **ストレージ** | 200 MB 以上の空き容量 | 1 GB 以上（プラグインやログ保存を考慮） |
| **ディスプレイ** | 1280 x 720 | 1920 x 1080 (Full HD) |

## 3. 技術的な補足

### 3.1 グラフィックス (JavaFX / Hardware Acceleration)
JavaFX は UI の描画にハードウェアアクセラレーションを利用します。一般的なビジネス向け PC であれば問題なく動作しますが、極端に古いグラフィックスドライバを使用している場合は、描画が遅くなる可能性があります。

### 3.2 メモリ管理（実装ポリシー）
OREOでは、メモリ使用量を極限まで抑えることを重要な実装ポリシーとしています。
- **最大メモリ割り当て (Xmx)**: **1 GB 〜 2 GB** を推奨しますが、通常利用時はこれより大幅に低い消費電力・消費メモリを目指します。
- **データ構造の最適化**: 巨大なテキストファイルを開いた場合でも、UI の応答性を損なわず、かつメモリ消費を一定以下に保つよう、メモリ効率の良いデータ構造（Gap Buffer や Piece Table など）を厳選して採用します。
- **リーク防止**: 定期的なプロファイリングを行い、不要なオブジェクトの保持やメモリリークを徹底的に排除します。
