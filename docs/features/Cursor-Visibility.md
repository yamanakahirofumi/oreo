# カーソル・行の視認性向上 (Cursor & Line Visibility)

OREO では、ユーザーが編集中の位置を即座に把握できるよう、デフォルトの JavaFX `TextArea` では不十分な視認性を向上させるための複数の手法を検討しています。

## 1. 提案される手法

以下の手法を組み合わせ、または選択可能にすることで視認性を高めます。

### 1.1 カレント行の背景強調 (Current Line Highlighting)
- **内容**: カーソルが存在する行全体の背景色を、他の行と僅かに異なる色（例：濃いグレーや薄いブルー）で塗りつぶします。
- **メリット**: どの行を編集しているかが一目で分かります。
- **技術的課題**: 標準の `TextArea` では実装が困難であり、`RichTextFX` への移行またはカスタムスキンの実装が必要です。

### 1.2 行番号表示とアクティブ行の強調 (Line Numbers with Active Indicator) [実装済み]
- **内容**: エディタの左端に行番号を表示する「ガター（Gutter）」を設け、現在の行番号を太字にしたり、色を変えたりします。
- **状況**: 設定で ON/OFF 可能な基本機能を実装済み。
- **今後の課題**: 現在の行番号を太字や色で強調する機能の追加。

### 1.3 ガターマーカー (Gutter Marker)
- **内容**: 行番号のすぐ横に、現在の行を示す小さなアイコン（三角形の矢印や垂直のバー）を表示します。
- **メリット**: 行番号そのものを注視しなくても、視界の端で位置を把握できます。

### 1.4 カーソル形状の強化 (Enhanced Cursor)
- **内容**: 標準の細い I-beam カーソルではなく、以下のような形状を採用します。
    - **ブロックカーソル (Block Cursor)**: 文字一つ分を覆う矩形のカーソル。
    - **太い I-beam**: 標準よりも視認性の高い太さ。
    - **アンダーライン型**: 文字の下に線を引く形状。
- **メリット**: カーソルそのものの紛失を防ぎます。

### 1.5 クロスヘア・ガイド (Crosshair Guide)
- **内容**: カーソル位置を中心に、水平線（および必要に応じて垂直線）を薄く表示します。
- **メリット**: 広い画面で作業している際に、正確な位置を把握しやすくなります。

## 2. 実装の優先順位と方針

「シンプル・ミニマル」のコンセプトを維持しつつ、以下の順序での検討を推奨します。

1.  **行番号表示 + アクティブ行強調**: エディタとしての基本機能であり、視認性向上への寄与も大きいため。
2.  **カレント行の背景強調**: 最も直感的な方法。`RichTextFX` 導入のタイミングで実装を検討。
3.  **カーソル形状のカスタマイズ**: 設定画面からの切り替えを可能にする。

## 3. 技術的要件

これらの機能の多くは、JavaFX 標準の `TextArea` の制限を超えるものです。
[条件付きスタイル表示](./Conditional-Styling.md) で検討されている `RichTextFX` 等への移行が、視認性向上の実現においても鍵となります。
